# Employee Management System

A Java-based application to manage employee records using CRUD operations.

### Technologies
- Java
- Spring Framework
- Hibernate ORM
- MySQL
- Maven

### Features
- Add employees
- Search employee by ID
- View all employees
- Update employee salary
- Delete employees

### How to Run
1. Clone the repository.
2. Configure MySQL credentials in `AppConfig.java`.
3. Run `Main.java` to start the application.
